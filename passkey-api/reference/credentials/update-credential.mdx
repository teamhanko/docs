---
openapi: openapi-passkeys patch /{tenant_id}/credentials/{credential_id}
---

Send `name`, `is_mfa`, or both. Omitted fields remain unchanged. Setting `is_mfa` to `false` permits standalone login under the tenant's normal WebAuthn policy; `true` restricts the credential to MFA use.

This is an administrative permission change and does not verify possession or change the authenticator's capabilities. Read [Change a credential's permitted usage](/passkey-api/mfa#change-a-credentials-permitted-usage) before enabling standalone login.
